# Security policy

## Scope

This policy covers the original documentation, prompt, templates, workflow files, and scripts maintained in this repository. Bundled upstream components may have their own security policies; report those issues to the relevant upstream project listed in `THIRD_PARTY_NOTICES.md`.

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability. Use GitHub's private vulnerability reporting feature when it is available for this repository, or contact the maintainer privately through the GitHub account that owns the repository.

Include a concise description, affected path and version or commit, safe reproduction steps, impact, and a suggested remediation if known. Redact secrets, personal data, and sensitive target details. Do not test unauthorized systems.

## Response expectations

Reports are triaged in good faith. Please allow time for confirmation, a fix, and coordinated disclosure before publishing exploit details.
