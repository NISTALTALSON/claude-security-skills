# Code of Conduct

We want this project to be useful, respectful, and safe for security engineers, developers, and researchers.

Participants must act in good faith, respect privacy, avoid harassment, and keep security work within authorized scope. Do not publish credentials, personal data, unauthorized target information, or weaponized exploit material in issues, discussions, pull requests, or documentation.

Maintainers may remove content or restrict participation when behavior conflicts with these standards. For sensitive security concerns, follow `SECURITY.md` instead of opening a public issue.
